# ⚡ RealityChecker

[![Python](https://img.shields.io/badge/Python-3.10%2B-blue.svg)](https://www.python.org/)
[![License](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)
[![AsyncIO](https://img.shields.io/badge/AsyncIO-High%20Performance-orange.svg)]()

**RealityChecker** — высокоскоростной асинхронный сканер для обнаружения и аудита прокси-серверов **VLESS-Reality**, маскирующихся под чужие SNI (Server Name Indication), а также анализа SSL/TLS инфраструктуры.

---

## 🚀 Ключевые возможности

* ⚡ **Высокая производительность (AsyncIO):** Сканирует от 500 до 2000+ одновременных сокетов с минимальным потреблением ресурсов.
* 🎯 **Детектирование Reality / TLS 1.3:** Точный анализ поведения протокола VLESS-Reality, работающего строго поверх TLS 1.3 с чужими сертификатами.
* 🌐 **Умный фильтр CDN / Edge (Без ложных срабатываний):** Автоматически распознает легитимные Anycast/CDN ноды (Akamai, Cloudflare, Fastly, AWS CloudFront, Google, Microsoft, Qrator) и исключает их из базы подозрительных хостов.
* 🔍 **Глобальный охват:** Проверяет абсолютно любые доменные зоны (`.com`, `.net`, `.org`, `.io`, `.ru`, `.de` и др.) с возможностью фильтрации по TLD (`--tld`).
* 💾 **Компактная SQLite база данных:** В базу сохраняются **только подтвержденные Reality/VPN сервера** с автоматической дедупликацией и счетчиком подтверждений (`hits`).
* 🔄 **Аудит изменений (`--check-fixed`):** Проверка ранее сохраненных хостов — кто исправился и установил свой сертификат, кто выключил прокси, а кто продолжает маскироваться.

## 📦 Установка

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/Kukuryzen/RealityChecker.git
   cd RealityChecker
   ```

2. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

## 🛠 Примеры использования

### 1. Быстрое сканирование подсети на 500 потоках:
```bash
python reallitychecker.py 185.220.101.0/24 -c 500
```

### 2. Сканирование с проверкой альтернативных портов (HTTPS + Cloudflare):
```bash
python reallitychecker.py 185.220.101.0/24 -p 443,8443,2053,2083 -c 800
```

### 3. Фильтрация по конкретной доменной зоне (например, только `.ru`):
```bash
python reallitychecker.py 185.220.101.0/24 --tld ru
```

### 4. Вывод только найденных Reality/VPN в консоли с экспортом в файл:
```bash
python reallitychecker.py 185.220.101.0/24 --only-vpn -o reality_found.txt
```

### 5. Аудит базы — проверка, кто исправился или выключился:
```bash
python reallitychecker.py --check-fixed
```

### 6. Экспорт всех активных серверов из базы:
```bash
python reallitychecker.py --export-vpn active_servers.txt
```

### 7. Очистка базы от неактивных/мертвых хостов:
```bash
python reallitychecker.py --purge-dead
```

## ⚙️ Аргументы командной строки

| Флаг | Описание |
| :--- | :--- |
| `target` | Сканируемая подсеть CIDR (например, `192.168.1.0/24`) или одиночный IP |
| `-p, --ports` | Порты через запятую (по умолчанию: `443`) |
| `-c, --concurrency` | Количество одновременных асинхронных сокетов (по умолчанию: `500`) |
| `--timeout` | Таймаут соединения в секундах (по умолчанию: `2.5`) |
| `--tld` | Фильтр по доменной зоне (например: `ru`, `com`, `org`) |
| `--only-vpn` | Отображать в консоли только найденные Reality/VPN сервера |
| `--check-fixed` | Провести аудит всей базы и проверить статус каждого хоста |
| `--export-vpn <file>`| Экспортировать активные VPN-сервера в текстовый файл |
| `--purge-dead` | Удалить неактивные хосты (`is_active = 0`) из базы данных |
| `--db <file>` | Путь к файлу SQLite базы данных (по умолчанию: `reality_vpn_servers.db`) |
